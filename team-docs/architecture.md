# Архитектура

Архитектура приложения состоит из слоёв.

## FastAPI (API Layer)

**Функция:** Принимает HTTP-запросы, валидирует входные данные, делегирует выполнение Celery задачам.

**Взаимодействует с:** Celery (через `.delay()`), Dishka (через `@inject`).

**Объекты:** `api/routes/*.py` (эндпоинты), `api/schemas.py` (Pydantic-схемы запросов/ответов).

---

## Dishka (DI Layer)

**Функция:** Управляет жизненным циклом зависимостей, scope'ами (APP/REQUEST), инъекцией через constructor injection.

**Взаимодействует со всеми слоями — поставляет зависимости.

**Объекты:** `di.py` (MainProvider, ChatOpenAIProvider, DbProvider, ApiProviders), `CeleryProvider`, `container_async`, `container`.

---

## Providers

**Функция:** Cоздание и настройка клиентов для внешних зависимостей, создание классов-сервисов, классов-репозиториев и т. п. 

**Взаимодействует с:** Service (предоставляет API), DI (через `@provide`/`@decorate`).

**Объекты:** `providers/**`

**Правила** создание каждого инстанса класса должно быть в отдельной provide-функции

---

## Celery

**Функция:** Асинхронная обработка задач (background tasks), periodic tasks (Beat).

**Взаимодействует с:** FastAPI (выполняет `.delay()`), Dishka (интеграция через `DishkaTask`), Service (выполняет бизнес-логику).

**Объекты:** `celery_/app.py` (task definitions:), `celery_/provider.py`, `celery_/setup.py`.

---

## Service Layer

**Функция:** Реализация бизнес-сценариев — оценка по файлам, новостям, законам, инцидентам; оркестрация Agent, Repository, Provider.

**Взаимодействует с:** Agent, Repository, Provider, DI (получает зависимости).

**Объекты:** `services/**`.

---

## Repository Layer

**Функция:** Абстракция доступа к базе данных, CRUD-операции для сущностей, управление транзакциями.

**Взаимодействует с:** Service (предоставляет доступ к данным), DI (получает `session`), Data Model, Dto.

**Объекты:** `repositories/**`.

**Правила**  Целевая библиотека для репозиториев - Advanced Alchemy

---

## Data Model

**Функция:** SQLAlchemy-модели базы данных

**Взаимодействует с:** Repository,

**Объекты:** `db/models/**`.

**Правила**  Целевая библиотека для репозиториев - Advanced Alchemy

---

## DTO (Data Transfer Object)

**Функция:** Используется для передачи данных из Repository в сервис

**Взаимодействует с:** Repository, Service

**Объекты:** `dtos/**`.

**Правила**  Целевая библиотека для репозиториев - Advanced Alchemy

---

## Agent (LangGraph)
**Условия** Используется для агентов, использующих langgraph

**Функция:** Оркестрация сложной логики анализа через граф состояний `RisksState`.

**Взаимодействует с:** Service (выполняет анализ), Node (элементы графа), Repository (сохранение состояния).

**Объекты:** `agent.py`.

---

## Node Layer
**Условия** Используется для агентов, использующих langgraph

**Функция:** Узлы графа Agent — каждый выполняет отдельную задачу в пайплайне анализа.

**Взаимодействует с:** Agent (часть графа), Service (черезDI), Repository (для сохранения состояния).

**Объекты:** `nodes/*.py`.
